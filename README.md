# rpg-prototype-python

RPG Prototype (Python)

Prototype de jeu vidéo de type RPG développé en Python, réalisé en équipe dans le cadre d'un projet personnel.

  Projet en cours de développement / test — ce dépôt contient une base de travail (structure des personnages, statistiques, idées de systèmes de jeu) et n'est pas un jeu jouable dans son état actuel.

  Équipe

  Concept

Un RPG avec un système de personnages jouables ayant chacun leurs propres statistiques (HP, force, défense, vitesse, chance, et une statistique originale : le Spectrion).

Fonctionnalités déjà posées
  Gestion des personnages : une quinzaine de personnages définis avec leurs statistiques individuelles (hp, force, defense, vitesse, chance, spectrion, etat)
  Suivi de l'état des personnages : détection de la mort d'un personnage lorsque ses HP tombent à 0
  Affichage des statistiques d'un personnage donné
  Base du système d'objets/items (fioles de Spectrion à plusieurs niveaux)
  Fonctionnalités prévues (non développées à ce stade)

Les catégories suivantes sont prévues mais pas encore codées :

Menu : présentation des personnages, changement de personnage, gestion des équipements
Système de commerce (achat/vente d'objets)
Combat : parade, esquive, attaque spéciale
Déplacement : haut / bas / gauche / droite / saut
Interactions : avec les objets et les autres personnages
  Assets graphiques

Le dépôt contient également les premiers sprites et éléments graphiques du jeu :

Sprites de décors et de personnages (format .aseprite)
Plan de carte (.kra, réalisé sous Krita)
  Technologies utilisées
Python (logique de jeu)
Aseprite (création des sprites)
Krita (conception de la carte)
  Statut du projet

Prototype expérimental réalisé à plusieurs pour découvrir la conception d'un jeu vidéo (structuration des données, logique de personnages). Le projet n'a pas été poursuivi jusqu'à un jeu complet, mais pose les bases d'un système de statistiques et de personnages qui pourrait être repris et développé plus loin (interface graphique, moteur de jeu, système de combat complet, etc.).
